# lunarpc

[![CI Status](https://github.com/mbarbin/lunarpc/workflows/ci/badge.svg)](https://github.com/mbarbin/lunarpc/actions/workflows/ci.yml)
[![Coverage Status](https://coveralls.io/repos/github/mbarbin/lunarpc/badge.svg?branch=main)](https://coveralls.io/github/mbarbin/lunarpc?branch=main)

lunarpc --- **L**ightweight **U**nary **RPC** --- is a small set of OCaml
libraries I use to expose local services over HTTP/JSON as versioned,
unary RPCs, and to test and document them.
